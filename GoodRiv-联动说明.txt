Trilium 小树 1.3 · Good研究所联动

请把本压缩包里的 trilium-tree-sidebar 文件夹内容覆盖到你当前已安装小树插件的原文件夹，然后打开 chrome://extensions，点击小树的“重新加载”。沿用同一个原文件夹，扩展 ID 和 chrome.storage.local 中的地址、ETAPI Token 才会保留；不要另建一个文件夹作为新扩展加载。

如果 GoodRiv 是直接双击 web/index.html 打开的，还需在小树扩展详情中开启一次“允许访问文件网址”。这是 Chrome 对本地文件的权限要求，不是重新填写 Trilium 连接。若用 localhost 打开网页版，则无需文件网址开关。

Good研究所只让插件后台执行三项操作：检查连接、新建空白笔记、打开笔记。密钥不会传给 GoodRiv 网页，点击笔记后会新开 Trilium 网页标签，不会自动打开小树侧边栏。

研究笔记会自动建在 Trilium 的当天 Day Note 下，不读取小树设置里的普通父笔记 ID。

测试：打开 GoodRiv → Good研究所 → 检查小树连接；然后对一个 .riv 文件点击“新建笔记”。笔记标题为“文件名 Notes”，以后显示“打开笔记”。

顶部“新建”按钮位置：在小树底部“设置”中选择：今天的 Day Note、指定父笔记，或指定日历集合。日历集合需填它自己的 Note ID；新笔记会添加今天的 #startDate，作为全天事件显示。笔记树每一行的“＋”仍直接在该行下面新建。原先填过自定义父笔记 ID 的设置会保留；原先为空或 root 的默认改为今天的 Day Note。

Good研究所的研究笔记保持自动建立在今天的 Day Note 下，不随小树顶部“新建”按钮的位置切换。
